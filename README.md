# 🌳 Binary Search Tree Visualizer

A React-based visualizer for performing and displaying binary search tree (BST) operations in real-time. Easily insert, delete, search, traverse, and manage the depth of your tree, all with a beautiful interactive UI.

---

## 🚀 Features

- ✅ **Insert Node** — Add nodes to the tree (within a set max depth).
- 🗑️ **Delete Node / Clear Tree** — Remove specific nodes or reset the tree.
- 🔍 **Search Node** — Highlights a specific node if it exists.
- 📈 **Find Min / Max** — Highlights the minimum or maximum node.
- 🔁 **Traversals** — Inorder, Preorder, and Postorder.
- 🌲 **Max Depth Control** — Restrict the maximum depth of the tree.
- 📏 **Tree Depth Display** — See the current depth limit and block deeper inserts.
- 🎨 **Visual Feedback** — Colorful tree rendering with hover highlights.
